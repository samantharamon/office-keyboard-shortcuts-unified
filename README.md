## Run the sample

1. Clone or download the project files.
2. In a command prompt, go to the root of the project and run `npm install`.
3. Run `npm start` to start the local web server and sideload the add-in. The add-in opens in Excel by default, but the add-in is also sideloaded to PowerPoint and Word.
4. Select **Keyboard Shortcuts** from the ribbon to open the task pane.
5. Test the keyboard shortcuts listed in the task pane.
